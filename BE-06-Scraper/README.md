# BE-06-Scraper — Progressive 3-Stage Multi-Target Web Scraper

`BE-06-Scraper` is a production-grade, extensible web scraping service built with Python 3.12+. It implements a 5-stage ETL data gathering pipeline (**Fetch $\rightarrow$ Parse $\rightarrow$ Extract $\rightarrow$ Clean $\rightarrow$ Structure $\rightarrow$ Store**) combined with a strict **Politeness & Ethics Layer** (`robots.txt` enforcement, token-bucket rate limiting, transparent `User-Agent` headers, and exponential backoff).

The dataset output generated by this scraper is formatted into `.jsonl` files containing pre-built `text_chunk` blocks, designed for seamless integration as a **RAG (Retrieval-Augmented Generation)** search corpus in Week 6.

---

## 1. Architecture & Strategy Design

To combine high learning value with software engineering best practices, `BE-06-Scraper` uses a **Strategy Pattern Engine** supporting a **3-Stage Progressive Pipeline**. New scraping targets are added in sequential stages without breaking backward compatibility for earlier stages.

```
                              ┌────────────────────────┐
                              │     CLI Engine (main)  │
                              │  python main.py scrape │
                              └───────────┬────────────┘
                                          │
                                          ▼
                              ┌────────────────────────┐
                              │  Politeness Middleware │
                              │ (Robots + RateLimiter) │
                              └───────────┬────────────┘
                                          │
                                          ▼
                ┌─────────────────────────┼─────────────────────────┐
                │                         │                         │
                ▼                         ▼                         ▼
    ┌──────────────────────┐  ┌──────────────────────┐  ┌──────────────────────┐
    │  BooksTargetStrategy │  │  LeadsTargetStrategy │  │ KaggleTargetStrategy │
    │   (books.toscrape)   │  │   (dasoertliche.de)  │  │ (kaggle.com/datasets)│
    └───────────┬──────────┘  └───────────┬──────────┘  └───────────┬──────────┘
                │                         │                         │
                │     HTML Selectors      │    JSON-LD Microdata    │   Playwright / API
                │                         │                         │
                └─────────────────────────┼─────────────────────────┘
                                          │
                                          ▼
                              ┌────────────────────────┐
                              │   Pydantic Validation  │
                              │    (schemas.py)        │
                              └───────────┬────────────┘
                                          │
                                          ▼
                              ┌────────────────────────┐
                              │  Storage & RAG Sink    │
                              │ (Postgres + RAG JSONL) │
                              └───────────┬────────────┘
```

## 2. Source Code & File Structure

Here is a detailed breakdown of all files in the solution and their specific roles:

| File Path | Description / Responsibility |
| :--- | :--- |
| **`main.py`** | Primary application execution entrypoint. Invokes CLI parser and async main loop. |
| **`cli.py`** | Command-Line Interface module using `argparse`. Defines flags (`--target`, `--max-pages`, `--output`, `--city`, `--street`, `--query`). |
| **`config.py`** | Settings manager using `pydantic-settings`. Loads `.env`, computes escaped PostgreSQL connection DSN. |
| **`schemas.py`** | Pydantic v2 data models (`BookRecord`, `LeadRecord`, `DatasetRecord`, `ScrapeLogRecord`) with `ConfigDict(extra="forbid")`. |
| **`core/politeness.py`** | Ethics middleware: `RobotsParser` (`robots.txt` compliance), `RateLimiter` (token-bucket delay), `UserAgentManager`, `RetryBackoff` (`tenacity`). |
| **`core/base_target.py`** | Abstract Base Class `BaseTargetStrategy` defining the target execution interface. |
| **`targets/books_target.py`** | **Stage 1 Strategy**: Async HTTP fetcher & BeautifulSoup4 DOM parser for `books.toscrape.com`. |
| **`targets/leads_target.py`** | **Stage 2 Strategy**: URL parameter transformer, JSON-LD microdata extractor, and B2B vs. Person filter for `dasoertliche.de`. |
| **`targets/kaggle_target.py`** | **Stage 3 Strategy**: Playwright headless browser / REST API interceptor for `kaggle.com/datasets`. |
| **`cleaner/books_cleaner.py`** | Cleaning utilities for books: currency float parser, rating word-to-int mapper, stock quantity regex, HTML unescaper. |
| **`storage/models.py`** | SQLAlchemy ORM declarative models (`Book`, `Lead`, `Dataset`, `ScrapeLog`). |
| **`storage/database.py`** | SQLAlchemy database engine setup and session factory (`SessionLocal`). |
| **`storage/repository.py`** | Repository layer for database UPSERT operations (idempotent record persistence). |
| **`storage/rag_exporter.py`** | RAG Sink Exporter generating `.jsonl` files containing pre-formatted `text_chunk` blocks. |
| **`docker-compose.yml`** | Docker Compose manifest starting Postgres 16 container (`db`) + Liquibase migration runner (`db-migrate`). |
| **`db/migrate.Dockerfile`** | Dockerfile extending `liquibase/liquibase:4.27` with the PostgreSQL JDBC driver jar. |
| **`db/changelog/`** | Liquibase changelog master (`db.changelog-master.xml`) and versioned SQL changesets (`001` through `004`). |
| **`tests/unit/`** | Unit test suite for politeness engine, cleaners, and DOM parsing. |

## 4. Configuration & Environment Variables

All settings are configured via environment variables or `.env` files and loaded via `config.py`:

| Environment Variable | Default Value | Description |
| :--- | :--- | :--- |
| `POSTGRES_USER` | `postgres` | PostgreSQL database username. |
| `POSTGRES_PASSWORD` | `postgres` | PostgreSQL database password. |
| `POSTGRES_DB` | `flyrank_scraper` | PostgreSQL database name. |
| `POSTGRES_HOST` | `localhost` | PostgreSQL host address (`db` when running inside Docker Compose). |
| `POSTGRES_PORT` | `5432` | PostgreSQL port. |
| `USER_AGENT` | `FlyrankBot/1.0...` | Custom bot identification string sent in HTTP headers. |
| `DEFAULT_RATE_LIMIT_DELAY` | `0.5` | Minimum pause (in seconds) between consecutive requests to a host. |
| `MAX_RETRIES` | `3` | Maximum number of exponential backoff retry attempts for failed requests. |
| `DEFAULT_OUTPUT_FORMAT` | `jsonl` | Default output sink format. |

## 5. Usage Section

### Environment Setup

1. **Create and Activate Virtual Environment**:
   ```bash
   cd BE-06-Scraper
   python -m venv .venv
   source .venv/bin/activate        # On Linux/macOS
   # .venv\Scripts\activate          # On Windows
   ```

2. **Install Dependencies**:
   ```bash
   pip install -r requirements-dev.txt
   ```

3. **Configure Environment Variables**:
   Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```

4. **(Optional) Run PostgreSQL via Docker Compose**:
   ```bash
   docker compose up --build
   ```

### Running the Scraper CLI

Run `main.py` with the `scrape` subcommand:

#### 1. Stage 1: Run Books Scraper
```bash
python main.py scrape --target books --max-pages 1 --output books.jsonl
```
*Note on Item Count*: Each catalog index page on `books.toscrape.com` contains exactly **20 book items**. Specifying `--max-pages 1` fetches catalog page 1 (20 items) and scrapes their 20 detail pages. Specifying `--max-pages 2` scrapes page 1 + page 2 = 40 books.

#### 2. Stage 2: Run German B2B Leads Scraper
```bash
python main.py scrape --target leads --city Berlin --street "Berliner Allee" --max-pages 1 --output leads.jsonl
```

#### 3. Stage 3: Run Kaggle Datasets Scraper
```bash
python main.py scrape --target kaggle --query "machine learning" --limit 5 --output kaggle.jsonl
```

## 6. Testing Section

The project features a full test suite powered by `pytest` and `pytest-asyncio`.

### Running All Unit Tests

```bash
pytest
```

or using python module invocation:

```bash
python -m pytest
```

### Test Suite Breakdown

- `tests/unit/test_politeness.py`:
  - Validates `RobotsParser` behavior when handling `404 Not Found` ("Allow All") and `403 Forbidden` ("Disallow All").
  - Validates `RateLimiter` inter-request timing delay accuracy.

- `tests/unit/test_books_cleaner.py`:
  - Validates currency price string parsing (`"£51.77"` $\rightarrow$ `51.77`).
  - Validates star rating word conversion (`"star-rating Three"` $\rightarrow$ `3`).
  - Validates stock regex integer extraction (`"In stock (22 available)"` $\rightarrow$ `22`).
  - Validates HTML entity unescaping.

- `tests/unit/test_books_target.py`:
  - Validates HTML DOM detail page parsing against mock HTML fixtures.
